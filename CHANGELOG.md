# Changelog

## 0.3.0

- Native Sparkle updater: daily checks, a manual Check for Updates command, signed feeds and signed update archives.
- Public MIT-licensed source, contribution and security guidance, macOS CI, and reproducible release scripts.
- About, source-code and issue-reporting links.

## 0.2.0

- Monochrome dotted interface, adaptive compact controls, undo/redo, A/B preview, loop selection and zoom.
- WAV, MP3 and M4A exports; bundled replaceable LAME encoder.
- Double-click trim-edge and gain resets.
- Audio/video drop handling and first-audio-track extraction from supported videos.

## 0.1.0

- Initial Rust/GPUI macOS editor with streaming waveform analysis, native playback, trim/gain and WAV export.
